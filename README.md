# MCPlab
Built an MCP server built with FastMCP that allows AI agents to query real-time weather data from the National Weather Service API. Designing an input sanitization layer to defend against tool-poisoning attacks and expanding testing and integration with broader agentic workflows. Built with Python, FastMCP, MCP SDK, National Weather Service API
Allows the agent to get weather alerts, forcasts, and to see different weather conditions in any of the 50 states in the US. Integrated with Claude Code
